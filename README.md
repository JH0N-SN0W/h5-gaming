# Altaigame Box (h5gaming1)

English-only mobile H5 game box for `h5gaming1.altaimobile.com`.

- Static site: `index.html`, `css/`, `js/`, `games.json`
- ~100 MIT games embedded from [sausi-7/games](https://github.com/sausi-7/games) GitHub Pages
- Empty advertisement placeholders only (no AdSense/GPT scripts)
- See `NOTICE` for attribution

## Local preview

```bash
python3 -m http.server 8080
# open http://localhost:8080
```
